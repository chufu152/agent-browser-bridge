## 3. 发布候选版本与回滚方案

### 3.1 版本与发布

- 发布候选：`v0.1.0`，主分支 `main` 指向提交 `5d43372`（M5 完成后将推进）。
- 发布产物：`packages/extension/.output/chrome-mv3/`（构建产物不入库，由 `npm run build` 生成）。

### 3.2 发布流程

1. `npm run test`（全部包）+ `npm run typecheck` + `npm run build`。
2. 全量测试无阻断/严重缺陷。
3. 打 tag：`git tag v0.1.0 && git push origin v0.1.0`。
4. 记录 CHANGELOG。

### 3.3 回滚方案

| 场景 | 回滚动作 |
|---|---|
| 新版本功能回归 | `git revert <bad-commit>` 或回退到上一 tag |
| 扩展崩溃 | 在 `chrome://extensions` 重新加载上一版本的 `.output` |
| 桥接服务故障 | 回退到上一 tag 的 `packages/bridge`，重启本地服务 |
| 数据/审计异常 | 审计与操作状态为本地短期状态，可清空重建，不涉及用户凭据 |

回滚验证：回退后重新执行全量测试，确认无残留状态（会话、订阅、确认均随断连/过期失效）。

## 4. 用户操作说明（摘要）

### 4.1 首次安装

1. `cd packages/extension && npm install && npm run build`。
2. 打开 `chrome://extensions`，开启开发者模式，加载 `packages/extension/.output/chrome-mv3`。
3. 记录扩展 ID，注册原生消息 host：`node packages/bridge/native-host/register.mjs <extension-id>`。
4. 启动桥接服务：`npm run start -w packages/bridge`（监听 `ws://127.0.0.1:3000`）。

### 4.2 为 Agent 签发 token

```js
// 在桥接服务进程内或通过管理界面
bridge.tokens.issue('my-agent'); // 返回一次性 token
```

### 4.3 管理界面

- 点击扩展图标 → popup 查看「待确认操作」与「最近审计」。
- 高风险操作（支付/删除/发送/发布/账户安全、文件传输）会在 popup 显示，用户点「确认/拒绝」。

### 4.4 合规红线

- 只操作用户自己已渲染在本机页面上的内容。
- 不绕过登录墙/付费墙/验证码；不读取密码字段值、Cookie 与凭据。
- 高风险操作必须人工确认，Agent 无权自确认。
